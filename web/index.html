Kết nối không dây qua Wi-Fi

Không cần cáp · Android 11 trở lên · làm theo các bước dưới, chỉ cần một lần

  1. 1

    Cài Node.js và Android Platform-Tools một lần

    Wi-Fi cần một server nhỏ chạy trên máy tính cùng mạng với điện thoại (trình duyệt không tự nối mạng tới điện thoại được). Cài 2 phần mềm miễn phí sau:

    Tải Node.js (LTS) Tải Platform-Tools

    Giải nén Platform-Tools vào thư mục dự án để có screentodesktop/platform-tools/adb.exe (macOS/Linux: adb) — server tự tìm thấy adb.

  2. 2

    Chạy server trên máy tính

    Mở Terminal / PowerShell và chạy (lần sau chỉ cần lệnh cuối npm start):

    git clone https://github.com/Zionnocyper/screentodesktop.git
cd screentodesktop
npm install
npm run build
npm start

    Rồi mở http://localhost:8000. Nếu Windows hỏi “Allow adb to communicate…”, chọn Cho phép (mạng riêng tư) để tự tìm được điện thoại.

    Mở localhost:8000

  3. 3

    Bật Gỡ lỗi không dây trên điện thoại

    Điện thoại và máy tính phải nối vào cùng một router (không dùng Wi-Fi khách hay 4G). Trên điện thoại vào:

    Cài đặt›Tùy chọn nhà phát triển›Gỡ lỗi không dây›Bật›Ghép nối thiết bị bằng mã ghép nối

    Điện thoại sẽ hiện mã 6 số và địa chỉ IP:cổng — giữ màn hình đó mở.

  4. 4

    Ghép đôi bằng mã 6 số

    Điện thoại tự hiện ở mục Tìm thấy trong mạng → bấm Ghép đôi → nhập mã. Không thấy máy? Bấm nút dưới đây và gõ địa chỉ IP:cổng đang hiện trên điện thoại.

  5. 5

    Bấm Xem

    Điện thoại hiện trong danh sách với biểu tượng Wi-Fi xanh. Những lần sau chỉ cần chạy server và bật Gỡ lỗi không dây — máy tự kết nối lại, không phải ghép đôi nữa.

Đang cắm cáp vào server? Bấm nút Wi-Fi trên thẻ thiết bị rồi rút cáp — không cần ghép đôi (mất tác dụng khi điện thoại khởi động lại).

Hình giật? Vào Chất lượng, chọn bitrate 4 Mbps (Wi-Fi) và độ phân giải 1024 px.

Không thấy điện thoại? Kiểm tra cùng router, đã cho phép adb qua tường lửa, router không bật cách ly thiết bị (AP isolation).

Xem từ máy khác trong nhà? Chạy server với HOST=0.0.0.0 và ACCESS_PASSWORD=…, rồi mở http://IP-máy-tính:8000.

Bắt đầu nhanh

  1. Bật Gỡ lỗi USB trên điện thoại: Cài đặt → Thông tin điện thoại → chạm 7 lần vào Số hiệu bản tạo, rồi vào Tùy chọn nhà phát triển → bật Gỡ lỗi USB.
  2. Cắm cáp USB. Chọn Thêm thiết bị USB (WebUSB) hoặc dùng danh sách Thiết bị trên server. Không muốn dùng cáp (Android 11+): xem Hướng dẫn Wi-Fi.
  3. Chấp nhận hộp thoại “Cho phép gỡ lỗi USB?” trên điện thoại, rồi bấm Xem.
